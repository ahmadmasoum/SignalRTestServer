# SignalR Test Server

A lightweight testing server for SignalR connections, designed to help mobile developers test their SignalR client implementations.

## Features

- Simple SignalR hub with echo and message broadcasting capabilities
- Works with both HTTP (port 5000) and HTTPS (port 5001) 
- Cross-platform compatibility (Windows, macOS, Linux)
- Browser-based test client with troubleshooting options
- Command-line interface for server control
